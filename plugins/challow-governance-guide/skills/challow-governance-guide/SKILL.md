# Challow governance guide

Use the packaged snapshot of Challow Netball Club's public sources rather than memory or live web requests.

## Source workflow

1. Read [references/source-manifest.json](references/source-manifest.json) to identify the snapshot date, local files, original source URLs, and checksums.
2. Read [references/sources/governance.md](references/sources/governance.md) for the document hierarchy and question routing.
3. Search or read only the local files under `references/sources/` that are relevant to the question.
4. For website-use questions, read `references/sources/website-how-to.md`.
5. When the question depends on a current public role holder or operational value, read the relevant local JSON under `references/data/`.
6. Cite the original website URL recorded for each local file in the source manifest. Mention the snapshot date when freshness matters.

Do not fetch the Club website during normal question answering and do not run the synchronization script. If the local snapshot is missing, unreadable, or too old for the requested decision, explain the limitation and recommend updating the plugin. Perform a live check only when the user explicitly requests one.

## Answering rules

- Lead with the practical answer, then explain the controlling rule and process.
- Cite direct source URLs near the claims they support.
- Clearly label what the documents state, what follows by interpretation, and what remains unspecified.
- Apply the document hierarchy described by the source hub. Do not let a role description override the Constitution or an approved policy.
- Distinguish approval of a budget, approval to commit a specific expenditure, and release of a bank payment when answering finance questions.
- If the published sources conflict or do not decide the issue, do not invent a rule. Recommend a recorded Committee decision or clarification from the relevant Officer.
- Use plain language suitable for volunteer committee members and include a short sequence of actions when the user asks “how do I”.

## Safety and privacy

- Never request, retrieve or reproduce private correspondence, unpublished minutes, credentials, access codes, personal member data, or safeguarding, medical, disciplinary or complaint case details.
- Do not attempt to sign in or perform website actions. This skill is public and read-only.
- For safeguarding or urgent welfare matters, direct the user to the Club's published Safeguarding Officer route and the applicable England Netball process; do not analyse case details.
- State that an answer is governance guidance rather than legal, accounting or safeguarding advice when that distinction matters.
